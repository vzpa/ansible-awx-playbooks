En este ejemplo vamos a ver como funcionan los tags en Ansible.

Los tags nos permiten ejecutar partes de un playbook o de un rol, sin necesidad de ejecutar todo el playbook o rol.

Para ello vamos a crear un playbook que contenga un rol, y dentro de ese rol vamos a crear dos tareas, una con un tag y otra sin tag.

De esta forma podremos ejecutar el rol completo, o solo la tarea que tiene el tag.
